# Boondock Edge — Release Notes

All notable changes, features, and fixes are documented here.
Each release is tagged with its version/branch name, date, and a summary of what changed.

---

## How to Use

- Run `release.bat` to build and package a release.
- The script will prompt you for release notes before packaging.
- Notes are automatically appended to this file under a new release section.
- You can also manually edit this file at any time to add context or corrections.

---

## [v1.6.6 — 31 Oct 2025]

**Branch:** `v1.6.6_31_oct_25`

### What's New
- Initial tracked production release.
- Stable backend with audio recording, transcription, and settings management.
- Frontend UI with dashboard, recorder management, and system configuration.
- Install/remove/restart shell scripts for edge device deployment.
- UDP service for device discovery and communication.
- Firmware folder bundled in release package.
- Docusaurus documentation site integrated into build.
