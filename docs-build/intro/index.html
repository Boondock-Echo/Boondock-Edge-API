Welcome to Boondock Edge Documentation

Welcome to the comprehensive documentation for Boondock Edge - an intelligent audio recording and monitoring system.

What is Boondock Edge?​

Boondock Edge is a complete audio recording solution that:

  • Records audio from multiple channels simultaneously
  • Transcribes audio to text automatically using AI
  • Stores recordings securely with timestamps and metadata
  • Monitors communications in real-time
  • Provides search through transcripts and recordings
  • Manages devices remotely through a web interface

Features​

Multi-Channel Recording​

Monitor multiple audio sources simultaneously with independent channel configuration.

Real-Time Transcription​

Automatic speech-to-text conversion using advanced AI models.

Smart Search​

Find recordings quickly using keywords, dates, channels, or metadata filters.

Device Management​

Configure and monitor recording devices remotely through the web interface.

User Management​

Role-based access control with granular permissions for different user roles.

Dark Mode​

Comfortable viewing experience in any lighting condition.
