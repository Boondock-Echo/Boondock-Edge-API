Live Audio Streaming Integration Guide

This document provides step-by-step instructions for integrating live audio streaming from the UDP Audio Recorder Service into your own JavaScript/Python applications.

Overview​

The UDP Audio Recorder Service runs on port 5000 and provides:

  • Real-time audio streaming via WebSocket (Socket.IO)
  • REST API for channel status and metadata
  • Support for multiple channels (ports 6001-6006 by default)
  • Audio format: 16-bit PCM, 8000 Hz, mono, little-endian

Architecture​

┌─────────────────┐         ┌──────────────────┐         ┌─────────────────┐
│  Your App       │         │  Audio Service   │         │  UDP Devices    │
│  (Port 4000)    │◄───────►│  (Port 5000)     │◄────────│  (Ports 6001+)  │
│                 │ WebSocket│                  │  UDP     │                 │
└─────────────────┘         └──────────────────┘         └─────────────────┘

Prerequisites​

  1. UDP Audio Recorder Service running on port 5000
  2. Socket.IO client library in your dashboard
  3. Modern browser with Web Audio API support

Step 1: Enable CORS (Optional - for REST API)​

The SocketIO connection already has CORS enabled (cors_allowed_origins="*"). If you plan to use REST API endpoints, add CORS headers to Flask routes.

Option A: Using flask-cors (Recommended)​

Add to app.py after Flask app creation:

from flask_cors import CORS

app = Flask(__name__, template_folder='templates', static_folder='static')
app.config['SECRET_KEY'] = 'stream-receiver-secret'

# Add CORS for REST API routes
CORS(app, resources={r"/api/*": {"origins": "*"}})

Add to requirements.txt:

flask-cors>=4.0.0

Option B: Manual CORS Headers​

Add this function to app.py:

@app.after_request
def after_request(response):
    response.headers.add('Access-Control-Allow-Origin', '*')
    response.headers.add('Access-Control-Allow-Headers', 'Content-Type,Authorization')
    response.headers.add('Access-Control-Allow-Methods', 'GET,PUT,POST,DELETE,OPTIONS')
    return response

Step 3: Audio Stream Player Module​

Create audioStreamPlayer.js in your dashboard:

/**
 * Audio Stream Player - Connects to UDP Audio Recorder Service
 * Usage: 
 *   const player = new AudioStreamPlayer('http://localhost:5000');
 *   player.connect();
 *   player.startPlayback(channelId);
 */

class AudioStreamPlayer {
    constructor(serverUrl) {
        this.serverUrl = serverUrl; // e.g., 'http://localhost:5000' or 'http://192.168.1.100:5000'
        this.socket = null;
        this.audioContexts = {};
        this.audioBuffers = {};
        this.activePlays = {};
        this.channels = [];
        this.isConnected = false;
        
        // Callbacks
        this.onChannelsUpdate = null;
        this.onConnectionChange = null;
    }

    /**
     * Connect to the audio service
     */
    connect() {
        if (this.socket && this.socket.connected) {
            console.log('Already connected');
            return;
        }

        // Import socket.io-client if using module system
        // const io = require('socket.io-client');
        // Or use global io if loaded via CDN

        this.socket = io(this.serverUrl, {
            reconnectionDelay: 1000,
            reconnection: true,
            reconnectionAttempts: 10,
            transports: ['websocket', 'polling']
        });

        this.socket.on('connect', () => {
            console.log('Connected to audio service at', this.serverUrl);
            this.isConnected = true;
            if (this.onConnectionChange) this.onConnectionChange(true);
            this.loadChannels();
        });

        this.socket.on('disconnect', () => {
            console.log('Disconnected from audio service');
            this.isConnected = false;
            if (this.onConnectionChange) this.onConnectionChange(false);
        });

        this.socket.on('connect_error', (error) => {
            console.error('Connection error:', error);
        });

        // Listen for initial status
        this.socket.on('initial_status', (data) => {
            if (data.streams && Array.isArray(data.streams)) {
                this.channels = data.streams;
                if (this.onChannelsUpdate) this.onChannelsUpdate(this.channels);
            }
        });

        // Listen for stream updates
        this.socket.on('stream_packet', (data) => {
            this.updateChannelStatus(data);
        });

        // Listen for device connection events
        this.socket.on('device_connected', (data) => {
            console.log('Device connected:', data);
            this.loadChannels(); // Refresh channel list
        });

        this.socket.on('device_disconnected', (data) => {
            console.log('Device disconnected:', data);
            this.loadChannels(); // Refresh channel list
        });
    }

    /**
     * Disconnect from the audio service
     */
    disconnect() {
        // Stop all active playback
        Object.keys(this.activePlays).forEach(channelId => {
            this.stopPlayback(parseInt(channelId));
        });

        if (this.socket) {
            this.socket.disconnect();
            this.socket = null;
        }
        this.isConnected = false;
    }

    /**
     * Load channel list from REST API
     */
    async loadChannels() {
        try {
            const response = await fetch(`${this.serverUrl}/api/status`);
            if (!response.ok) {
                throw new Error(`HTTP error! status: ${response.status}`);
            }
            const data = await response.json();
            if (data.streams) {
                this.channels = data.streams;
                if (this.onChannelsUpdate) this.onChannelsUpdate(this.channels);
            }
        } catch (error) {
            console.error('Error loading channels:', error);
        }
    }

    /**
     * Update channel status when packets arrive
     */
    updateChannelStatus(data) {
        const channel = this.channels.find(c => c.channel_id === data.channel_id);
        if (channel) {
            channel.packet_count = data.packet_count || channel.packet_count;
            channel.byte_count = data.byte_count || channel.byte_count;
            channel.last_packet_time = data.last_packet_time || channel.last_packet_time;
            if (this.onChannelsUpdate) this.onChannelsUpdate(this.channels);
        }
    }

    /**
     * Get channel by port number
     */
    getChannelByPort(port) {
        return this.channels.find(c => c.port === port);
    }

    /**
     * Get channel by channel ID
     */
    getChannelById(channelId) {
        return this.channels.find(c => c.channel_id === channelId);
    }

    /**
     * Start audio playback for a specific channel
     * @param {number} channelId - Channel ID (0-5) or port number
     * @param {boolean} usePort - If true, channelId is treated as port number
     */
    startPlayback(channelId, usePort = false) {
        // If using port number, find channel ID
        if (usePort) {
            const channel = this.getChannelByPort(channelId);
            if (!channel) {
                console.error(`Channel with port ${channelId} not found`);
                return;
            }
            channelId = channel.channel_id;
        }

        // Check if channel exists
        const channel = this.getChannelById(channelId);
        if (!channel) {
            console.error(`Channel ${channelId} not found`);
            return;
        }

        // Stop existing playback if any
        if (this.activePlays[channelId]) {
            this.stopPlayback(channelId);
        }

        // Initialize audio buffer
        if (!this.audioBuffers[channelId]) {
            this.audioBuffers[channelId] = [];
        }

        // Create Web Audio Context
        const sampleRate = 8000;
        let audioContext;
        try {
            audioContext = new (window.AudioContext || window.webkitAudioContext)({
                sampleRate: sampleRate,
                latencyHint: 'interactive'
            });
        } catch (e) {
            console.warn('Could not create AudioContext with 8000 Hz, using default:', e);
            audioContext = new (window.AudioContext || window.webkitAudioContext)();
        }

        let isPlaying = true;

        // Request playback start from server
        if (this.socket && this.socket.connected) {
            this.socket.emit('start_playback', { channel_id: channelId });
        } else {
            console.error('Socket not connected');
            return;
        }

        // Listen for audio stream
        const audioHandler = (data) => {
            if (data.channel_id === channelId && isPlaying) {
                try {
                    // Decode base64 to binary
                    const binary = atob(data.audio);
                    const bytes = new Uint8Array(binary.length);
                    for (let i = 0; i < binary.length; i++) {
                        bytes[i] = binary.charCodeAt(i);
                    }
                    this.audioBuffers[channelId].push(bytes);
                } catch (e) {
                    console.error('Error decoding audio:', e);
                }
            }
        };

        if (this.socket) {
            this.socket.off('audio_stream', audioHandler);
            this.socket.on('audio_stream', audioHandler);
        }

        // Convert 16-bit PCM to float samples
        const convertPCMToFloat = (pcmData) => {
            const float32Array = new Float32Array(pcmData.length / 2);
            let index = 0;
            let s_index = 0;

            while (index < pcmData.length) {
                // Read 16-bit signed integer (little-endian)
                const sample = pcmData[index] | (pcmData[index + 1] << 8);
                // Convert to signed
                const s16 = sample < 32768 ? sample : sample - 65536;
                // Normalize to -1 to 1
                float32Array[s_index++] = s16 < 0 ? s16 / 32768 : s16 / 32767;
                index += 2;
            }
            return float32Array;
        };

        // Continuous playback loop using ScriptProcessorNode
        const bufferSize = 4096;
        const scriptProcessor = audioContext.createScriptProcessor(bufferSize, 0, 1);
        let currentIndex = 0;
        let currentBuffer = null;

        scriptProcessor.onaudioprocess = (event) => {
            const output = event.outputBuffer.getChannelData(0);
            const buffer = this.audioBuffers[channelId];

            let outputIndex = 0;

            while (outputIndex < bufferSize) {
                // Load next buffer if needed
                if (!currentBuffer || currentIndex >= currentBuffer.length) {
                    if (buffer.length === 0) {
                        // No data available, fill with silence
                        while (outputIndex < bufferSize) {
                            output[outputIndex++] = 0;
                        }
                        break;
                    }

                    // Convert next chunk to float
                    const rawBytes = buffer.shift();
                    currentBuffer = convertPCMToFloat(rawBytes);
                    currentIndex = 0;
                }

                // Copy samples to output
                while (outputIndex < bufferSize && currentIndex < currentBuffer.length) {
                    output[outputIndex++] = currentBuffer[currentIndex++];
                }
            }
        };

        // Connect to speakers
        scriptProcessor.connect(audioContext.destination);

        // Resume audio context if suspended
        if (audioContext.state === 'suspended') {
            audioContext.resume();
        }

        // Store references for stopping
        this.activePlays[channelId] = {
            stop: () => {
                isPlaying = false;
                scriptProcessor.disconnect();
                audioContext.close();

                // Notify server to stop streaming
                if (this.socket && this.socket.connected) {
                    this.socket.emit('stop_playback', { channel_id: channelId });
                }

                if (this.socket) {
                    this.socket.off('audio_stream', audioHandler);
                }

                this.audioBuffers[channelId] = [];
            }
        };

        console.log(`Started playback for channel ${channelId} (port ${channel.port})`);
    }

    /**
     * Stop audio playback for a specific channel
     * @param {number} channelId - Channel ID or port number
     * @param {boolean} usePort - If true, channelId is treated as port number
     */
    stopPlayback(channelId, usePort = false) {
        // If using port number, find channel ID
        if (usePort) {
            const channel = this.getChannelByPort(channelId);
            if (!channel) {
                console.error(`Channel with port ${channelId} not found`);
                return;
            }
            channelId = channel.channel_id;
        }

        if (this.activePlays[channelId]) {
            this.activePlays[channelId].stop();
            delete this.activePlays[channelId];
            console.log(`Stopped playback for channel ${channelId}`);
        }
    }

    /**
     * Check if a channel is currently playing
     */
    isPlaying(channelId, usePort = false) {
        if (usePort) {
            const channel = this.getChannelByPort(channelId);
            if (!channel) return false;
            channelId = channel.channel_id;
        }
        return !!this.activePlays[channelId];
    }

    /**
     * Get all available channels
     */
    getChannels() {
        return this.channels;
    }
}

// Export for module systems
if (typeof module !== 'undefined' && module.exports) {
    module.exports = AudioStreamPlayer;
}

React Component​

import React, { useEffect, useState } from 'react';
import AudioStreamPlayer from './audioStreamPlayer';

function AudioStreams() {
    const [player, setPlayer] = useState(null);
    const [channels, setChannels] = useState([]);
    const [connected, setConnected] = useState(false);
    const [playing, setPlaying] = useState({});

    useEffect(() => {
        // Initialize player
        const audioPlayer = new AudioStreamPlayer('http://localhost:5000');
        
        audioPlayer.onChannelsUpdate = (channels) => {
            setChannels(channels);
        };

        audioPlayer.onConnectionChange = (isConnected) => {
            setConnected(isConnected);
        };

        audioPlayer.connect();
        setPlayer(audioPlayer);

        return () => {
            if (audioPlayer) {
                audioPlayer.disconnect();
            }
        };
    }, []);

    const playByPort = (port) => {
        if (player) {
            player.startPlayback(port, true);
            setPlaying({ ...playing, [port]: true });
        }
    };

    const stopByPort = (port) => {
        if (player) {
            player.stopPlayback(port, true);
            setPlaying({ ...playing, [port]: false });
        }
    };

    return (
        <div>
            <h1>Live Audio Streams</h1>
            <p>Status: {connected ? 'Connected' : 'Disconnected'}</p>
            
            <div className="channels">
                {channels.map(channel => (
                    <div key={channel.channel_id} className="channel-card">
                        <h3>Channel {channel.channel_id} - Port {channel.port}</h3>
                        <p>Status: {channel.connected ? 'Connected' : 'Disconnected'}</p>
                        <p>Device: {channel.device_ip || 'None'}</p>
                        <p>Packets: {channel.packet_count || 0}</p>
                        <button 
                            onClick={() => playByPort(channel.port)}
                            disabled={!channel.connected || playing[channel.port]}
                        >
                            Play
                        </button>
                        <button 
                            onClick={() => stopByPort(channel.port)}
                            disabled={!playing[channel.port]}
                        >
                            Stop
                        </button>
                    </div>
                ))}
            </div>
        </div>
    );
}

export default AudioStreams;

Step 5: Python Backend Proxy (Optional)​

If you want to proxy requests through your Python backend:

Flask Example​

from flask import Flask, jsonify
import requests

app = Flask(__name__)

AUDIO_SERVICE_URL = 'http://localhost:5000'

@app.route('/api/audio/channels')
def get_audio_channels():
    """Proxy to get audio channels"""
    try:
        response = requests.get(f'{AUDIO_SERVICE_URL}/api/status')
        return jsonify(response.json())
    except Exception as e:
        return jsonify({'error': str(e)}), 500

@app.route('/api/audio/channel/<int:channel_id>/status')
def get_channel_status(channel_id):
    """Proxy to get specific channel status"""
    try:
        response = requests.get(f'{AUDIO_SERVICE_URL}/api/status/{channel_id}')
        return jsonify(response.json())
    except Exception as e:
        return jsonify({'error': str(e)}), 500

API Reference​

WebSocket Events​

Client → Server​

  • start_playback: Start audio streaming

    socket.emit('start_playback', { channel_id: 0 });

  • stop_playback: Stop audio streaming

    socket.emit('stop_playback', { channel_id: 0 });

Server → Client​

  • initial_status: Initial channel status on connection

    {
      streams: [
        {
          channel_id: 0,
          port: 6001,
          connected: true,
          device_ip: "192.168.1.100",
          packet_count: 1234,
          byte_count: 567890,
          // ... more fields
        }
      ]
    }

  • audio_stream: Audio data chunk

    {
      channel_id: 0,
      audio: "base64_encoded_audio_data",
      chunk_size: 8192
    }

  • stream_packet: Packet received notification

    {
      channel_id: 0,
      device_ip: "192.168.1.100",
      packet_size: 1612,
      packet_count: 1235,
      // ... more fields
    }

  • device_connected: Device connected event

    {
      channel_id: 0,
      device_ip: "192.168.1.100",
      device_port: 54321,
      timestamp: "2025-01-01T12:00:00Z"
    }

  • device_disconnected: Device disconnected event

    {
      channel_id: 0,
      device_ip: "192.168.1.100",
      device_port: 54321,
      timestamp: "2025-01-01T12:00:00Z"
    }

REST API Endpoints​

  • GET /api/status: Get status of all channels
  • GET /api/status/<channel_id>: Get status of specific channel
  • GET /api/audio/<channel_id>: Get audio chunk (raw PCM bytes)

Usage Examples​

Basic Usage​

// Initialize
const player = new AudioStreamPlayer('http://localhost:5000');
player.connect();

// Play audio from port 6001
player.startPlayback(6001, true); // true = use port number

// Play audio from channel 0
player.startPlayback(0, false); // false = use channel ID

// Stop playback
player.stopPlayback(6001, true);

// Get all channels
const channels = player.getChannels();

// Get channel by port
const channel = player.getChannelByPort(6001);

With Callbacks​

const player = new AudioStreamPlayer('http://localhost:5000');

    // Update your UI
};

};

Configuration​

Audio Service URL​

Update the URL based on your environment:

// Local development
const AUDIO_SERVICE_URL = 'http://localhost:5000';

// Same server, different port
const AUDIO_SERVICE_URL = 'http://localhost:5000';

// Remote server
const AUDIO_SERVICE_URL = 'http://192.168.1.100:5000';

// Production (use environment variable)
const AUDIO_SERVICE_URL = process.env.AUDIO_SERVICE_URL || 'http://localhost:5000';

Port Mapping​

Default port mapping:

  • Channel 0 → Port 6001
  • Channel 1 → Port 6002
  • Channel 2 → Port 6003
  • Channel 3 → Port 6004
  • Channel 4 → Port 6005
  • Channel 5 → Port 6006

Ports are configurable via the audio service configuration.

Audio Format​

  • Sample Rate: 8000 Hz
  • Bit Depth: 16-bit
  • Channels: Mono (1 channel)
  • Byte Order: Little-endian
  • Encoding: Signed integer PCM

Troubleshooting​

Connection Issues​

  1. Cannot connect to audio service

    • Verify the audio service is running on port 5000
    • Check firewall settings
    • Verify CORS is enabled

  2. No audio playback

    • Check browser console for errors
    • Verify channel is connected (device sending data)
    • Check Web Audio API support in browser

  3. Audio is choppy or delayed

    • Check network latency
    • Verify sufficient buffer size
    • Check CPU usage

Common Errors​

  • "Channel with port X not found": Channel not initialized or device not connected
  • "Socket not connected": WebSocket connection lost, check network
  • "Error decoding audio": Invalid base64 data, check server logs

Quick Start Checklist​

  • Audio service running on port 5000
  • Add CORS headers to audio service (optional for REST API)
  • Install Socket.IO client in your dashboard
  • Copy audioStreamPlayer.js to your dashboard
  • Import and initialize in your app
  • Use player.startPlayback(port, true) to play by port number
