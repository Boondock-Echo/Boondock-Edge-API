Dashboard Guide

The Dashboard is the central hub for viewing, managing, and analyzing all recorded audio communications.

Overview​

The Dashboard provides real-time access to transcribed recordings with powerful filtering, search, playback, and organization capabilities. The interface is divided into three main areas:

  • Sidebar (Left Panel) - Search, channels, and keywords
  • Message List (Center Panel) - Recordings display
  • Top Bar (Controls) - Filtering and view settings

Features​

Sidebar Components​

  • Search Bar - Real-time search through all recordings
  • Channel List - Toggle channels on/off, view status indicators
  • Keywords Section - Highlight keywords in recordings

Message List​

  • Message Cards - Individual recordings with transcriptions
  • Audio Playback - Play, pause, seek through recordings
  • Metadata - Timestamps, channels, tags, and more

Top Bar Controls​

  • Multi-Select Mode - Select multiple messages for batch operations
  • Time Filters - Filter by time ranges (Last 30 mins, 1 hour, etc.)
  • Custom Filters - Advanced date/time range filtering
  • View Settings - Toggle column visibility

Common Tasks​

Finding a Recent Recording​

  1. Use the time filter dropdown to select "Last 1 hour" or "Last 24 hours"
  2. Search for keywords from the conversation
  3. Results show matching messages with highlighted search terms

Monitoring a Specific Channel​

  1. In the sidebar, click toggle switches for channels you want to monitor
  2. Only recordings from selected channels will appear
  3. Channel status indicators show if channel is currently recording

Creating an Incident Report​

  1. Enable multi-select mode
  2. Check messages to include in report
  3. Click "Create Report" button
  4. Add report title, notes, and metadata

For more detailed information, refer to the interactive documentation available in the application.
