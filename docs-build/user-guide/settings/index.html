Settings Guide

The Settings page provides comprehensive configuration options for your Boondock Edge system.

Overview​

Settings are organized into several tabs:

  • Summary - System health, device status, and metrics
  • Recorders - Device management and firmware updates
  • Global - System-wide configurations
  • System - Advanced administration and maintenance
  • Logs - System and device logging

Summary Tab​

The Summary tab provides an overview of:

  • Recording statistics by day
  • Errors and warnings
  • Users and login history
  • Device management toggles

Device Management​

Enable automatic detection for:

  • Uniden BC125AT scanners
  • ESP32 Boondock Edge recorders
  • USB audio devices

Recorders Tab​

Manage your recording devices:

  • Device Enumeration - Scan and connect to devices
  • Firmware Management - Upload and manage ESP32 firmware
  • Stations - Configure recording channels

Global Tab​

Configure system-wide settings:

  • Transcription services and models
  • Language and timezone preferences
  • Backup and restore options
  • Network interfaces and hotspot (post-install device setup: scripts/WIFI_HOTSPOT_SETUP.md in the repo)
  • Branding customization

System Tab​

Advanced administration tools:

  • Network interface configuration
  • Hotspot setup
  • Backup and restore operations
  • System maintenance
  • System health monitoring
  • Danger zone (factory reset, data clearing)

Logs Tab​

View and analyze system logs:

  • Critical Logs - Errors and system failures
  • Warning Logs - Non-critical warnings
  • Communication Logs - Transcription activity
  • Database Logs - Database operations
  • Event Logs - System events
  • Device Logs - Device-specific logs

For detailed field descriptions and troubleshooting, refer to the interactive documentation in the application.
