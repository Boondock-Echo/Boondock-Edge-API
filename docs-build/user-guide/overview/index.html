User Guide Overview

This guide will help you understand and use Boondock Edge effectively.

Table of Contents​

  1. Dashboard - Main interface overview
  2. Settings - Configuration options
  3. Recorders - Device management
  4. Logs - System logging and troubleshooting

Main Components​

Dashboard​

The Dashboard is the central hub for viewing and managing audio recordings. It provides real-time access to all recorded communications with powerful filtering, search, and playback capabilities.

Settings​

Configure system-wide settings including transcription services, device management, global configurations, and system maintenance.

Recorders​

Manage Boondock Edge recording devices, firmware, and station configuration.

Logs​

View system logs, device logs, and application logs organized by type for troubleshooting and monitoring.

Getting Help​

If you need assistance:

  • Check the Troubleshooting section
  • Review the CLI Reference for device configuration
  • Consult the Hardware Guide for device setup
